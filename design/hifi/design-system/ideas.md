# Ideas (out of P1 scope)

Ideas that go beyond the features in product.md or §10.1. None of them appears in the main frames.

- **⋯ slot count badge**: Show “+9” inside or beside the ⋯ slot so users know how many categories are hidden. Needs NEW copy for the spoken label.
- **Different glyph for the default “Other” category**: The default “Other” category uses more_horiz, the same glyph as the ⋯ slot. Restyling the glyph behind the key (e.g. category) would remove the last ambiguity; key stays more_horiz.
- **Category limit marker on ring icons**: §10.1 #6: a thin progress ring around ring icons whose category has a limit; error-coloured when over. Behaviour unchanged, purely visual.
- **“Backup & data” sub-page**: Move Export / Restore / CSV / Automatic backup into one sub-page with a status summary row in Settings. Shortens Settings by ~6 rows.
- **Recent searches**: Keep the last 5 queries in memory (not persisted) and show them as chips on an empty query.
- **Password visibility + strength hint**: Visibility toggle is in P1; a strength hint would need NEW copy and is optional.
- **Widget: one-tap category shortcuts (4 × 2)**: The stretched widget could show the top 3 ring categories as extra buttons (deep link already supports category=).
- **Max-amount specific error**: §10.1 #14: NEW “Amount is too large” instead of “Invalid calculation” above 10¹².
