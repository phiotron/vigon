# MoneyMainFirst

How amounts appear when accounts use different currencies: the main currency comes first.

The main amount is `body-md` at weight 600. The original amount goes on a second line in `body-sm` and `ink-muted`, and is shown only when it differs from the main currency. Screen readers read "$4.50, from ₫117,000". Totals are always in the main currency and say so ("Total in USD", "in USD").
