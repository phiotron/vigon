# CategoryAvatar

Category avatars at 40 and 48 dp, the ⋯ "More categories" slot, and grid cells.

Categories are filled discs (`cat-NN` + `on-cat` glyph, FILL 1). The ⋯ slot is deliberately **not** a category: a `surface` disc with a 2 dp dashed `outline` ring and an outlined `more_horiz` in `ink-muted`. That matters because the default "Other" category uses the same glyph. Selected grid cell = a 2 dp `ink` ring with a `surface-container` gap.
