# Keypad

The app's own number keypad and the amount display (a live region). Unchanged from v1 apart from the snackbar position.

Keys are 56 dp (`tap-key`). ÷ × − + = use `secondary-container`. `000` appears for 0-decimal currencies and `.` otherwise. The wide key reads "Choose category" until a category is set, then "Save" (D-018: choosing a category saves).
