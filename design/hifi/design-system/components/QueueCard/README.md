# QueueCard

An import-queue card: bank amount ≈ main, payee, content, source account, category strip with Suggested, actions.

Two cards fit at 360 × 800. The suggested category gets a ring and a tag, and the primary button names it ("Save to Food"). With no suggestion, one tap on a category saves. The amount is shown in the bank's currency first because that is what the receipt says; this is the only exception to main-first.
