# Feedback

Snackbars (with action, stacked, 10-second with timer) and progress indicators (spinner, linear, button "Working").

Snackbar: `inverse-surface` / `inverse-ink`, action in `inverse-primary` at weight 600, `radius-sm`, `shadow-float`. It floats 12 dp above the − / + buttons, the keypad or sheet footers. Past one line of text the action moves under it. The 10-second variant shows a 2 dp timer line. It is a polite live region.
