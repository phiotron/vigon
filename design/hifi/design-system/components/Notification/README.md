# Notification

The daily reminder notification (EXT-02) on Android and iOS, the monochrome small icon and the app icon.

Title "Ví Gọn", body "Have you recorded your spending today?". It never contains figures. On Android the small icon is a monochrome silhouette (redrawn here, ASSUMPTION A16), shown in a `brand-deep` circle; on iOS the full app icon is used.
