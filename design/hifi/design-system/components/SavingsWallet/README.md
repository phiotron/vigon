# SavingsWallet

Savings goal cards backed by a wallet account, in all states: days left, reached, overdue.

Progress bar uses `primary`, or `income` when reached; there is always % text beside it. Deadline chip: neutral when days are left, ok (✓ Reached) when done, warn (Overdue). The reminder line appears when a "Remind me" choice is set. Add money is a tonal button and is hidden once the goal is reached.
