Xuất bản sao lưu, xuất CSV và khôi phục từ file .vigon.

- Xuất: ghi file tạm rồi mở bảng chia sẻ của hệ điều hành (khung viền đứt trong thiết kế là phần của hệ điều hành, app không vẽ).
- Khôi phục: trình chọn file hệ thống → hộp thoại “Dữ liệu hiện tại sẽ bị thay thế…” → Đồng ý → thông báo thành công hoặc “File không hợp lệ…”.
