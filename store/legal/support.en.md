## Frequently asked questions

**Where is my data?**
Only on your phone. Vigon has no server, no account and sends no data anywhere. See the Privacy Policy for details.

**I forgot my PIN — can I recover it?**
No. The app stores only a hash of the PIN, which nobody can reverse, including us. If you forget it, you must uninstall and reinstall the app — data on the phone is lost. That is why you should export a backup file regularly.

**How do I move to a new phone?**
On the old phone: Settings → Data → Export backup, then send or save the `.vigon` file outside the app (Files, Drive, email…). On the new phone: install Vigon → Settings → Restore from backup → pick that file. Email mailboxes and app passwords do not travel in the backup file; add the mailbox again on the new phone.

**Automatic backup is not running.**
Check that the switch is on, a folder is chosen and a time is set. On Android the phone needs battery, and the system may delay the run by a few minutes; turn off battery optimisation for Vigon if your phone often skips it. On iPhone a closed app cannot run on its own: at the set time you get a notification — tap it or open Vigon to back up. If the time is missed, the app catches up when you open it again.

**I changed the backup password — will old files still open?**
An old file opens with the password that was set when it was created. Passwords are not stored anywhere; if you forget one, the file cannot be opened.

**What is the CSV export for?**
For opening in Excel, Google Sheets or another tool. A CSV file is a snapshot of your figures and **cannot** be restored into the app — use a `.vigon` backup file to restore.

**Bank email import shows no entries.**
This version supports only **MB Bank** and three email providers: Gmail, Yahoo, iCloud. The app reads only mail that arrives **after** you add the mailbox, only **successful** transaction emails, and a parsed item stays in the **Queue** until you pick a category and confirm it. Open the mailbox screen to see sign-in errors or "emails could not be read". If the bank changes its email template, the app may skip that email — record the expense by hand.

**Does Vigon read other mail or mark messages as read?**
No. The app downloads only messages from the bank's addresses, reads them in view-only mode, and does not mark them as read, edit, delete or move them.

**I want to report a security issue.**
Email the address above with a subject starting with "Security issue". You can also use the "Report a security issue" row in Settings → About. We will respond and will never ask you to send passwords or real data.
